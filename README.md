# APEX Detail

Демонстрационный сайт детейлинга для портфолио Захара.

**Сайт:** https://quaali.github.io/detailing-demo/

Тёмная автомобильная эстетика, лаймовый акцент и крупная типографика. Адаптивная страница на чистых HTML, CSS и JavaScript — без сборки и библиотек.

## Что работает

- Навигация по разделам и мобильное меню.
- Меню услуг с переходом к калькулятору.
- Выбор типа кузова и нескольких услуг; множители 1 / 1,2 / 1,4.
- Два независимых сравнения «до/после»: кузов и салон GLE 63 Coupé, с клавиатурным управлением.
- Просмотр изображений в модальном окне; закрытие кнопкой, Escape и по фону.
- Подготовка и копирование текста запроса без отправки данных.
- Раскрывающиеся ответы на вопросы, анимации появления и индикатор прокрутки.
- Поддержка prefers-reduced-motion, фокус клавиатуры и семантическая разметка.

## Запуск

Открой `index.html` в браузере или используй VS Code Live Server. Для локального сервера:

```sh
python3 -m http.server 4173
```

Затем открой http://localhost:4173. Clipboard API работает на localhost и HTTPS; при запрете доступа сайт выделит текст для ручного копирования.

## Структура

- `index.html` — блоки страницы, калькулятор и диалоги.
- `style.css` — стили, адаптивность и анимации.
- `script.js` — расчёт стоимости, меню, галерея, сравнение и копирование.
- `assets/` — локальные изображения и favicon.

## Важное о демонстрации

APEX Detail — вымышленный бренд. Цены иллюстративные. Реальные контакты и обработка заявок не подключены. Сравнение «до/после» показывает две AI-иллюстрации одного автомобиля в гараже с одинаковым ракурсом, а не результат реальной работы. Отзывы и статистика клиентов не выдуманы и не добавлены.

Для реального клиента нужно заменить бренд, цены, фотографии, контакты, подключить выбранный канал записи и проверить его.

## Изображения и шрифт

- `assets/gle-interior-before-medium-plus.webp` и `assets/gle-interior-after.webp` — созданные встроенным ImageGen состояния салона Mercedes-AMG GLE 63 Coupé C292 2018 года. Чистый кадр служит исходником для загрязнённого состояния с сохранением ракурса. Чистый кадр сохранён; состояние «до» показывает умеренное загрязнение приборки, сидений и ковра без отпечатков обуви. Промпт умеренного загрязнения: `assets/gle-interior-medium-plus-prompt.txt`; исходный промпт чистого состояния: `assets/gle-interior-prompts.txt`.

- `assets/garage-gle-63-before.webp` и `assets/garage-gle-63-after.webp` — два сгенерированных состояния чёрного Mercedes-AMG GLE 63 Coupé 2018 года (C292) в детейлинг-гараже. Для состояния «до» использован кадр «после» с сохранением композиции. Созданы встроенным ImageGen. Подробности: `assets/garage-gle-63-prompts.txt`.

- `assets/bmw-m4-g82-lime-ai.webp` — оригинальная AI-иллюстрация BMW M4 G82 в лаймовом цвете, созданная встроенным OpenAI ImageGen специально для этого сайта. Тёмная студия, отражения световых линий и свободное пространство слева. Полный промпт: `assets/bmw-m4-g82-ai-prompt.txt`. Исходник: `outputs/bmw-m4-g82-lime.png` в рабочем проекте. Предыдущая реальная фотография больше не используется на странице; её лицензия остаётся в `assets/bmw-m4-g82-license.txt`.
- `assets/porsche.jpg` — [исходный файл](https://images.unsplash.com/photo-1503376780353-7e6692767b70).
- `assets/bmw.jpg` — [исходная фотография Unsplash](https://images.unsplash.com/photo-1492144534655-ae79c964c9d7).
- Manrope загружается из Google Fonts, при отсутствии сети используется Arial.

Все фотографии, необходимые для страницы, хранятся в репозитории.
