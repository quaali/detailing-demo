# APEX Detail

Демонстрационный сайт детейлинга для портфолио Захара.

**Сайт:** https://quaali.github.io/detailing-demo/

Тёмная автомобильная эстетика, лаймовый акцент и крупная типографика. Адаптивная страница на чистых HTML, CSS и JavaScript — без сборки и библиотек.

## Что работает

- Навигация по разделам и мобильное меню.
- Меню услуг с переходом к калькулятору.
- Выбор типа кузова и нескольких услуг; множители 1 / 1,2 / 1,4.
- Интерактивное сравнение изображения с клавиатурным управлением.
- Просмотр изображений в модальном окне; закрытие кнопкой, Escape и по фону.
- Подготовка и копирование текста запроса без отправки данных.
- Раскрывающиеся ответы на вопросы, анимации появления и индикатор прокрутки.
- Поддержка prefers-reduced-motion, фокус клавиатуры и семантическая разметка.

## Запуск

Открой `index.html` в браузере или используй VS Code Live Server. Для локального сервера:

```sh
python3 -m http.server 4173
```

Затем открой http://localhost:4173. Clipboard API работает на localhost и HTTPS; при запрете доступа сайт выделит текст для ручного копирования.

## Структура

- `index.html` — блоки страницы, калькулятор и диалоги.
- `style.css` — стили, адаптивность и анимации.
- `script.js` — расчёт стоимости, меню, галерея, сравнение и копирование.
- `assets/` — локальные изображения и favicon.

## Важное о демонстрации

APEX Detail — вымышленный бренд. Цены иллюстративные. Реальные контакты и обработка заявок не подключены. Сравнение «до/после» — фильтрация одной фотографии, а не результат реальной работы. Отзывы и статистика клиентов не выдуманы и не добавлены.

Для реального клиента нужно заменить бренд, цены, фотографии, контакты, подключить выбранный канал записи и проверить его.
